基于 HarmonyOS 的帕金森运动迟缓量化评测系统

Released HarmonyOS Huawei Cloud IoTDA OpenHarmony Feature Extraction Data Filtering

一个将大数据、物联网与现代医疗相结合的帕金森运动迟缓量化评测系统。帮助轻症患者在家完成手颤抖动、手指弯曲、肌电信号等数据采样，实现疾病的早诊断、早治疗，降低医疗机构评估负荷和患者经济与心理负担。

🔧 核心技术

  • 华为云 IoT 端侧规则引擎 — 通过 IoTDA 设置联动规则，基于 SQL 规则引擎云端一键下发至设备，在端侧直接完成设备联动
  • OpenHarmony 分布式软总线 — 设备间端侧直连通信，降低对网络质量的依赖，提高整体联动效率
  • 云边协同数据处理 — 特征提取算子、滤波算子等云端算子下发至传感设备，在端侧完成无效数据过滤与屏蔽

FMFD — 频谱分析仪频率测量与故障诊断系统

Released Qt / C++ VISA / SCPI BRB Reasoning Fault Diagnosis Spectrum Analyzer

硕士研究核心成果。FMFD (Frequency Measurement and Fault Diagnosis) 是一个基于 Qt 的频谱分析仪频率测量与智能故障诊断桌面系统，集仪器控制、自动化数据采集、BRB 推理诊断与可视化于一体，面向高性能测试仪器的精密故障定位。

🔧 核心技术

  • BRB 诊断引擎 — 基于信念规则库 (Belief Rule Base) 的多模块故障概率推理，覆盖 RF 前端、本振系统、时钟系统、校准系统、数字处理 (ADC/FPGA) 与电源模块
  • 自动化数据采集 — 通过 VISA/TCPIP 协议远程控制信号发生器与频谱分析仪，支持分段扫描与批量导入两种采集模式
  • 特征提取与诊断 — 提取幅度误差、频率误差、参考电平偏移三大诊断特征，实现系统级与模块级故障定位
  • Python 集成可视化 — 系统结构图、故障症状热力图等多维度可视化展示

🏗 系统架构

  • 仪器控制层：InstrumentController — 标准 SCPI 指令集，TCPIP Socket 通信
  • 数据采集层：DataAcquisitionService — 实时采集、参数校验、断点续测
  • 诊断推理层：BRBEngine — 层次化信念规则库推理，多模块概率输出
  • 方案管理层：SchemeManager — 测试方案持久化存储与快速加载
